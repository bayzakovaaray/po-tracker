# Портфель проектов ПО — сайт

Страница трекера для GitHub Pages. Данные хранятся в Neon Postgres и доступны только по коду.

- `index.html` — трекер целиком.
- `schema.sql` — схема базы: таблицы в закрытой схеме `po`, наружу открыты только функции `po_*`, каждая проверяет код или сессию.
- `jwks.json` — открытый ключ для анонимного токена Neon Data API (секретов здесь нет).

## Коды доступа

Задаются в Neon → SQL Editor:

```sql
select po.set_codes('код редактора', 'код просмотра');
```

Код не короче 8 символов. Смена кодов выкидывает всех, кто вошёл.
